# 支持

感谢使用 **HearRelay**。本页面汇集常见问题的排查方法以及联系方式。

> 本翻译仅为方便阅读而提供。若本译本与[英文版本](/en/support/)之间存在任何冲突,以英文版本为准。

## 快速帮助

### 尝试配对时显示"未找到设备"

两台设备需要：

1. 登录**同一 Apple ID**
2. 连接到**同一 Wi-Fi 网络**(同一子网)
3. 在 iOS 设置中启用 **iCloud**
4. 已向 HearRelay 授予**麦克风**和**本地网络**权限

如果仍然看不到对方设备,请点击配对选择界面上的刷新按钮,或在两台设备上重启应用。

### 音频卡顿或断续

- 靠近 Wi-Fi 路由器,或切换到 5 GHz 网络
- 接收信号差的蓝牙耳机可能造成声音中断 — 可尝试有线耳机或其他耳机
- 同一 Wi-Fi 下的大流量活动(大文件下载、视频通话)可能影响实时音频

### Standalone 模式下 AirPods 音质明显变差

在 Standalone 模式下,HearRelay 会将麦克风锁定为**内置麦克风**,以避免蓝牙被强制切换到低带宽模式（HFP）。请使用内置麦克风作为输入,仅将 AirPods 用作输出。这是产品设计。

### 录音没有被保留

录音会在**创建后 24 小时自动删除**,除非您点击"保留"。一旦保留,它们会一直保存到您删除为止。

### 锁屏后 HearRelay 停止录制

在屏幕锁定时,HearRelay 会在后台继续采集和中继音频。如果录制停止：

- 确认 HearRelay 的**后台应用刷新**已启用(iOS 设置 → 通用 → 后台应用刷新)
- 确认**低电量模式**未过度抑制后台任务
- 某些 iOS 版本会在其他音频应用接管时暂停音频会话 — 请关闭其他音频应用

### 灵动岛 / 锁屏界面上的图标消失了

Live Activities 受系统强制限制的最大持续时间(约 8 小时)。超过后,指示器可能停止更新,尽管 HearRelay 仍在运行。重新打开应用即可刷新。

## 权限清单

| 权限 | 用途 | 设置路径 |
|---|---|---|
| 麦克风 | 任何监听 | 设置 → HearRelay → 麦克风 |
| 本地网络 | 配对模式(向其他设备发送/接收) | 设置 → HearRelay → 本地网络 |
| iCloud（已登录） | 配对模式(发现您的其他设备) | 设置 → \[您的姓名\] → iCloud |
| 后台应用刷新 | 锁屏后仍持续监听 | 设置 → 通用 → 后台应用刷新 |

若本地网络或 iCloud 不可用,您仍可使用 **Standalone** 模式。
