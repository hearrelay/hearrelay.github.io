# 支持

感谢使用 **HearRelay**。本页面汇集疑难排解提示、关于合法使用的重要告知,以及联络方式。

## 重要告知

### 录音与监听法律因地区而异

录音及实时监听的相关法律因国家、州、省及使用地点而异。部分地区在录音之前要求获得**所有**当事人的同意。在工作场所、学校、租赁场所、医疗、长者照护、儿童看护及公共空间进行监听,可能需要特别告知、书面同意或许可。**除非依法获得允许,否则请勿录制对话或私人空间的声音。**存疑时,请勿录音。

您有责任确认您借由 HearRelay 所执行的任何录音或实时监听皆符合所有适用法律。禁止用途清单请见[使用条款 §3](/zh-Hans/terms/)。

### HearRelay 不是安全、医疗或紧急用设备

HearRelay 是一款用于便利监听的消费级实用工具。它**不是**医疗设备、紧急用设备、防盗警报、儿童看护安全设备、长者照护安全设备、生命维持设备,亦非任何经认证用于安全关键用途的设备。**切勿将 HearRelay 作为监护或紧急侦测的唯一手段。**请始终将其与负责任的直接监护以及任何经认证之安全设备搭配使用。

## 快速帮助

### 尝试配对时显示「未找到设备」

两台设备需要:

1. 登录**同一 Apple ID**
2. 连接至**同一 Wi-Fi 网络**(同一子网)
3. 在 iOS 设置中已启用 **iCloud**
4. 已向 HearRelay 授予**麦克风**与**本地网络**权限

若仍看不到对方设备,请点击配对选择界面上的刷新按钮,或在两台设备上重启本应用。

### 音频出现卡顿或断续

- 靠近 Wi-Fi 路由器,或切换至 5 GHz 网络
- 接收信号差的蓝牙耳机可能造成断续 — 可尝试有线或其他耳机
- 同一 Wi-Fi 下大量的网络流量(大文件下载、视频通话)可能影响实时音频

### 在 Standalone 模式下,AirPods 的音质明显变差

在 Standalone 模式下,HearRelay 会将麦克风限制为**内置麦克风**,以避免迫使蓝牙切换到低带宽模式(HFP)。请使用内置麦克风作为输入,仅以 AirPods 作为输出。这是产品设计。

### 录音没有被保留

录音会在**创建后 24 小时自动删除**,除非您于该录音上点击「**保留**」。一经保留,即会一直保存,直至您删除。

### 锁屏后 HearRelay 停止录制

在屏幕锁定时,HearRelay 会在后台继续采集与中继音频。若采集停止:

- 请确认已为 HearRelay 启用 **Background App Refresh**(iOS 设置 → 通用 → Background App Refresh)
- 请确认**低电量模式**未过度抑制后台任务
- 部分 iOS 版本会在其他音频应用接管时暂停音频会话 — 请关闭其他音频应用

### 灵动岛 / 锁屏界面上的图标消失了

Live Activities 受系统强制限制的最大持续时间(约 8 小时)。一旦达到,即便 HearRelay 仍在运作,该指示器也可能停止更新。重新打开本应用即可刷新。

**重要:**即使 Live Activity 或锁定屏幕小组件因系统限制停止更新,**在监听处于活动状态时,后台音频采集可能仍在继续**。请仅在合法且事先告知的监听情境中使用此功能。请勿将设备放置在可能采集到未获得法律所需告知或同意的人员声音的位置。在音频采集进行中,iOS 可能也会显示其系统级麦克风 / 隐私指示器。

## 购买与订阅

### HearRelay 是订阅制吗?

**不是。**HearRelay Full Access 为**非消耗型(Non-Consumable)的一次性购买**(买断式 IAP)。它**并非**自动续订订阅。14 日免费试用结束后,一次购买即可在您持续登录该 Apple ID 的期间长期解锁本应用。

### Family Sharing

本项解锁已启用 **Family Sharing**,因此您 Family Sharing 群组中的成员可无需额外费用使用 HearRelay Full Access。

### 如何恢复以往的购买?

打开本应用 → 点击锁定横幅 → **Restore Purchases**。Apple 会检查您 Apple ID 中的过往解锁,并予以重新应用。

### 如何申请退款?

App Store 购买的退款请求须通过 Apple 的标准退款流程提交,网址 <https://reportaproblem.apple.com>。Apple 依 App Store 与 Apple Media Services 条款处理退款。CONEX 不会收到付款卡号或账单详情。本段中的任何规定均不限制您依适用法律对 CONEX 可能享有的任何强制性消费者权利。

## 权限清单

| 权限 | 用途 | 设置路径 |
|---|---|---|
| 麦克风 | 任何监听 | 设置 → HearRelay → 麦克风 |
| 本地网络 | Pair 模式(向其他设备发送 / 接收) | 设置 → HearRelay → 本地网络 |
| iCloud(已登录) | Pair 模式(发现您的其他设备) | 设置 → \[您的姓名\] → iCloud |
| Background App Refresh | 锁屏后持续监听 | 设置 → 通用 → Background App Refresh |

若本地网络或 iCloud 不可用,您仍可使用 **Standalone** 模式。
