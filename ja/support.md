# サポート

**HearRelay** をご利用いただきありがとうございます。このページでは、よくあるお困りごとと、お問い合わせ窓口をご案内します。

## クイックヘルプ

### ペア接続で「端末が見つかりません」と表示される

ご利用の両端末が、以下のすべてを満たしている必要があります:

1. **同じ Apple ID** にサインインしている
2. **同じ Wi-Fi ネットワーク**(同じサブネット)に接続している
3. iOS の設定で **iCloud** が有効になっている
4. HearRelay に**マイク**と**ローカルネットワーク**の権限を許可している

それでも相手が見えない場合は、ペア候補画面で更新ボタンをタップするか、両端末でアプリを再起動してください。

### 音が途切れる・ぷつぷつ切れる

- Wi-Fi ルータに近づくか、5 GHz ネットワークに切り替える
- 電波の悪い Bluetooth ヘッドフォンはドロップアウトの原因になります。有線や別の機種をお試しください
- 同じ Wi-Fi で大容量ダウンロードやビデオ通話が動作しているとリアルタイム音声に影響します

### Standalone モードで AirPods の音質が低い

Standalone モードでは、Bluetooth が低帯域モード(HFP)に強制切替されるのを防ぐため、マイク入力を**内蔵マイクに固定**しています。入力は内蔵マイク、出力のみ AirPods にしてください。これは仕様です。

### 録音ファイルが消えた

録音ファイルは、**作成から 24 時間後に自動削除**されます(録音一覧で「保存」をタップした場合を除く)。一度「保存」すると、お客様が削除するまで残ります。

### 画面をロックすると録音が止まる

画面ロック中も録音・中継は継続するよう設計されています。もし止まる場合:

- **Background App Refresh** が HearRelay で有効か確認(設定 → 一般 → Appのバックグラウンド更新)
- **低電力モード**がバックグラウンドタスクを厳しく制限していないか確認
- iOS のバージョンによっては、別の音声アプリが割り込むと一時停止することがあります。その音声アプリを終了してみてください

### Dynamic Island / ロック画面の表示が消えた

Live Activities は OS の制約で最大表示時間(約 8 時間)があります。超過すると表示更新が止まりますが、HearRelay 自体は動作を続けていることがあります。アプリを開き直すと表示が更新されます。

## 権限チェックリスト

| 権限 | 必要な機能 | 設定パス |
|---|---|---|
| マイク | モニタリング全般 | 設定 → HearRelay → マイク |
| ローカルネットワーク | ペアモード(他端末への送受信) | 設定 → HearRelay → ローカルネットワーク |
| iCloud(サインイン) | ペアモード(他端末の検出) | 設定 → \[あなたの名前\] → iCloud |
| Appのバックグラウンド更新 | 画面オフ中の継続動作 | 設定 → 一般 → Appのバックグラウンド更新 |

ローカルネットワークや iCloud が利用できない場合でも、**Standalone** モードはご利用いただけます。
