## 重要なお知らせ

### 録音・モニタリングに関する法令は地域により異なります

録音及びライブモニタリングに関する法令は、国、州、地域、利用場所によって異なります。**関係者全員の同意を要する地域もあります。** 職場、学校、賃貸物件、医療・介護施設、公共空間でのモニタリングには、特別な通知、書面同意又は許可が必要となる場合があります。**法的に許可されていることを確認できない会話又は私的空間を録音しないでください。** 判断に迷う場合は、録音しないでください。

HearRelay によるあらゆる録音・ライブモニタリングが適用法令を遵守していることを確認する責任は、お客様にあります。禁止される利用については [利用規約 §3](/ja/terms/) をご覧ください。

### HearRelay は安全装置・医療機器・緊急通報装置ではありません

HearRelay は補助的なモニタリング用途の一般消費者向けユーティリティです。**医療機器、緊急通報装置、防犯警報装置、育児安全装置、高齢者・要介護者の安全装置、生命維持装置その他の安全用途に認証された機器ではありません。** 監督、見守り、異常検知又は緊急対応の**唯一の手段**として使用してはなりません。直接的な見守り、及び目的に応じて認証された安全機器との併用が前提です。

### HearRelay がインターネット越しに動作しない理由

HearRelay は、両端末が**同一の Apple ID にサインイン**しており、かつ**同一の Wi-Fi / ローカルネットワーク**に接続していることを意図的に必須としています。インターネットリレー、遠隔モニタリングモード、クラウド経路は提供しません。これは欠落機能ではなく、セキュリティ・プライバシー上の設計判断です。

- **盗撮・盗聴の遠隔悪用を防ぎます** — 盗難・貸与された iPhone から、誰かのご自宅の音声がインターネット越しに流出することがありません
- **音声を CONEX サーバに送信しません**(当社はサーバを運営していません)、また公衆インターネットにも流しません
- **Apple ID 漏洩の影響を、既にペアリング済みの端末群に限定**できます

ネットワーク越しのモニタリングが必要な場合、HearRelay は適切な選択肢ではありません。当該用途で認証された製品を、適切な親権者・雇用関係上又は法的通知のもとでご利用ください。

## クイックヘルプ

### ペア接続で「端末が見つかりません」と表示される

ご利用の両端末が、以下のすべてを満たしている必要があります。

1. **同じ Apple ID** にサインインしている
2. **同じ Wi-Fi ネットワーク**(同じサブネット)に接続している
3. iOS の設定で **iCloud** が有効になっている
4. HearRelay に**マイク**と**ローカルネットワーク**の権限を許可している

それでも相手が見えない場合は、ペア候補画面で更新ボタンをタップするか、両端末でアプリを再起動してください。

### 音が途切れる・ぷつぷつ切れる

- Wi-Fi ルータに近づくか、5 GHz ネットワークに切り替える
- 電波の悪い Bluetooth ヘッドフォンはドロップアウトの原因になります。有線や別の機種をお試しください
- 同じ Wi-Fi で大容量ダウンロードやビデオ通話が動作しているとリアルタイム音声に影響します

### Standalone モードで AirPods の音質が低い

Standalone モードでは、Bluetooth が低帯域モード(HFP)に強制切替されるのを防ぐため、マイク入力を**内蔵マイクに固定**しています。入力は内蔵マイク、出力のみ AirPods にしてください。これは仕様です。

### 録音ファイルが消えた

録音ファイルは、**作成から 24 時間後に自動削除**されます(録音一覧で「保存」をタップした場合を除く)。一度「保存」すると、お客様が削除するまで残ります。

### 画面をロックすると録音が止まる

画面ロック中も録音・中継は継続するよう設計されています。もし止まる場合:

- **Background App Refresh** が HearRelay で有効か確認(設定 → 一般 → Appのバックグラウンド更新)
- **低電力モード**がバックグラウンドタスクを厳しく制限していないか確認
- iOS のバージョンによっては、別の音声アプリが割り込むと一時停止することがあります。その音声アプリを終了してみてください

### Dynamic Island / ロック画面の表示が消えた

Live Activities は OS の制約で最大表示時間(約 8 時間)があります。超過すると表示更新が止まりますが、HearRelay 自体は動作を続けていることがあります。アプリを開き直すと表示が更新されます。

**重要:** Live Activity やロック画面ウィジェットの更新が OS の制約で止まっても、**モニタリング動作中はバックグラウンドでの音声取得が継続している場合があります**。本アプリは、合法かつ事前に開示された目的でのみご利用ください。法的に必要な通知又は同意を得ていない人々の音を捕捉し得る場所に端末を設置しないでください。音声取得中は、iOS のシステム側マイク/プライバシー インジケータも表示される場合があります。

## 購入・サブスクリプションについて

### HearRelay はサブスクリプションですか?

**いいえ。** HearRelay Full Access は **Non-Consumable 型の買い切り購入(IAP)** であり、自動更新サブスクリプションではありません。14 日間の無料試用期間後、一度の購入で、お客様が同じ Apple ID にサインインしている限り恒久的に解放されます。

### Family Sharing

本アンロックは **Family Sharing** に対応しており、Family Sharing グループのメンバーは追加料金なしで HearRelay Full Access をご利用いただけます。

### 過去の購入を復元するには?

アプリを開き、ロックされたバナー → **「購入の復元」** をタップしてください。Apple がお客様の Apple ID で過去のアンロックを確認し、再適用します。

### 返金は?

App Store での購入に関する返金申請は、Apple の標準的な返金手続(<https://reportaproblem.apple.com>)を通じて行う必要があります。返金処理は App Store 及び Apple Media Services Terms に従って Apple が行います。当社は、クレジットカード番号その他の請求先情報を受領しません。本記載は、適用法に基づきお客様が当社に対して有する強行的な消費者保護上の権利を制限するものではありません。

## 権限チェックリスト

| 権限 | 必要な機能 | 設定パス |
|---|---|---|
| マイク | モニタリング全般 | 設定 → HearRelay → マイク |
| ローカルネットワーク | ペアモード(他端末への送受信) | 設定 → HearRelay → ローカルネットワーク |
| iCloud(サインイン) | ペアモード(他端末の検出) | 設定 → \[あなたの名前\] → iCloud |
| Appのバックグラウンド更新 | 画面オフ中の継続動作 | 設定 → 一般 → Appのバックグラウンド更新 |

ローカルネットワークや iCloud が利用できない場合でも、**Standalone** モードはご利用いただけます。
